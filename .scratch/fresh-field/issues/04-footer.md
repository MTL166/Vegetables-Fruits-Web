# 04 — 页脚 Footer

## Parent

`.scratch/fresh-field/PRD.md`

## What to build

实现页脚区域。多列布局，包含：

- 品牌简介：鲜野集简介文字（2-3 句）
- 配送说明：冷链配送覆盖范围、配送时效简介
- 售后服务：坏果包赔、退换货政策链接
- 会员权益：会员专区、积分规则链接
- 联系方式：客服电话、工作时间

使用浅灰色背景（略深于 page 背景），文字使用 `--color-text-secondary`。

## Acceptance criteria

- [ ] 页脚包含品牌简介、配送说明、售后服务、会员权益、联系方式五个区域
- [ ] 多列水平排列，1440px 宽度下内容居中
- [ ] 文字颜色使用灰色辅助色
- [ ] 背景色略深于页面背景，有明显视觉区分
- [ ] 链接有 hover 效果
