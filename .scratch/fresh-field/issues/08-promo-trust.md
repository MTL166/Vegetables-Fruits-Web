# 08 — 限时优惠区与品质保障区

## Parent

`.scratch/fresh-field/PRD.md`

## What to build

实现首页的限时优惠横幅和品质保障两个区域：

**限时优惠区：**
- 浅绿色背景（`--color-primary-light`），全宽
- 左侧标题 "限时优惠"，右侧倒计时组件（静态展示，如 "还剩 2天 06:30:00"）
- 2-3 个促销商品卡片（复用 product-card 样式，额外显示折扣价和番茄红促销标签）
- 折扣价使用 `--color-accent-red`

**品质保障区：**
- 4 列网格，每列一个保障项
- 保障项：产地直采、冷链配送、坏果包赔、48 小时鲜达
- 每个包含图标（占位 SVG 或 emoji）+ 标题 + 一行简短说明文字

## Acceptance criteria

- [ ] 限时优惠区使用浅绿色背景，全宽
- [ ] 倒计时组件可见（静态展示即可，不需要实时倒计时）
- [ ] 促销商品使用番茄红标签和折扣价
- [ ] 品质保障区 4 列水平排列
- [ ] 每个保障项包含图标、标题、说明文字
- [ ] 两个区域视觉分隔清晰
