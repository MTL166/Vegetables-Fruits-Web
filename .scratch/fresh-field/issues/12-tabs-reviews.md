# 12 — Tab 标签页与评价卡片

## Parent

`.scratch/fresh-field/PRD.md`

## What to build

实现商品详情页的 Tab 标签页切换和用户评价区：

**Tab 标签页：** 三个标签 — 商品详情、产地信息、用户评价。当前激活标签下方有 2px 主绿色下划线，未激活标签为灰色。点击切换内容区域。

**商品详情内容：** 静态展示 — 新鲜采摘、低温锁鲜、精选分级、礼盒包装、适合家庭食用和节日送礼。

**产地信息内容：** 静态展示 — 产地、种植方式、采摘时间等信息。

**用户评价：** 3 条评价卡片（review-card），每条包含：
- 用户头像（圆形占位图）
- 用户名
- 星级评分（复用 rating）
- 评价文字
- 晒单缩略图（占位，1:1 小图）

## Acceptance criteria

- [ ] 三个 Tab 标签水平排列，点击可切换
- [ ] 当前激活标签底部有 2px 主绿色下划线
- [ ] 默认激活 "商品详情" Tab
- [ ] 切换 Tab 时对应内容区域正确显示/隐藏
- [ ] 商品详情内容包含 5 项卖点描述
- [ ] 产地信息包含产地相关数据
- [ ] 3 条评价卡片正确显示，包含头像、用户名、评分、评价文字、晒单图
