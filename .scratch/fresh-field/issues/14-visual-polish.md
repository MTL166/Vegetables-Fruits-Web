# 14 — 视觉打磨与跨浏览器验证

## Parent

`.scratch/fresh-field/PRD.md`

## What to build

对两个完成页面进行视觉打磨和跨浏览器验证：

**视觉打磨：**
- 统一检查所有组件间距、圆角、阴影是否与设计系统一致
- 优化首屏视觉重心（Hero 标题大小、按钮位置）
- 统一商品卡片图片尺寸
- 调整限时优惠区和品质保障区的视觉识别度
- 确保页面不拥挤、不杂乱，保持精品感
- 确认 "立即购买" 按钮在视觉层级上足够醒目

**跨浏览器验证：**
- Chrome 最新版 — 完整验证
- Edge 最新版 — 完整验证
- Firefox 最新版 — 完整验证
- 检查 hover 效果、CSS 变量、字体渲染一致性

**手动测试清单验证（根据 PRD）：**
- [ ] 页面在 1440px 宽度下无水平滚动条、无元素重叠
- [ ] 所有图片占位正确加载
- [ ] 所有 hover 状态正常触发
- [ ] 数量选择器边界值正确（最小值 1，不可减至 0）
- [ ] 缩略图点击正确切换主图
- [ ] Tab 切换正确显示对应内容

## Acceptance criteria

- [ ] 两个页面在 1440px 宽度下视觉统一、无拥挤或过度松散
- [ ] 所有按钮、卡片、间距符合设计令牌规范
- [ ] Chrome、Edge、Firefox 均无渲染异常
- [ ] 所有交互（hover、点击、切换）在三个浏览器中正常工作
- [ ] 手动测试清单全部通过
