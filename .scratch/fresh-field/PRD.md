# PRD: 鲜野集 Fresh Field PC 端精品生鲜电商前端

## Problem Statement

城市家庭消费者在线上购买生鲜蔬果时面临信任门槛高、商品品质不确定、购物体验不够清爽直观的问题。现有生鲜电商界面往往促销感过强、视觉嘈杂，难以传达"精品、新鲜、可信赖"的品牌感知。鲜野集需要通过一套清爽现代自然的 PC 端电商界面，降低用户的购买决策顾虑，建立品质信任，引导用户从浏览到下单的完整体验。

## Solution

构建一套纯 HTML/CSS/JS 的 PC 端静态电商前端界面（1440px 桌面分辨率），包含首页和商品详情页两个核心页面。采用明亮、干净、有呼吸感的自然风格设计，使用统一的设计系统（色彩、字体、组件规范），通过高质感商品图片、清晰的商品信息结构和明确的购买入口，打造精品生鲜电商的品牌形象。

## User Stories

1. 作为新访客，我想要在首屏看到品牌的核心价值主张，以便在 5 秒内理解鲜野集卖什么。
2. 作为消费者，我想要通过分类图标快速找到感兴趣的商品品类，以便高效浏览。
3. 作为注重品质的消费者，我想要看到商品的清晰图片、价格和规格信息，以便做出购买决定。
4. 作为消费者，我想要看到限时优惠信息，以便抓住促销机会节省开支。
5. 作为消费者，我想要看到品质保障说明（产地直采、冷链配送、坏果包赔等），以便放心购买生鲜商品。
6. 作为消费者，我想要在首页看到推荐商品，以便发现当季好物。
7. 作为消费者，我想要在商品详情页看到多角度商品图片，以便全面了解商品外观。
8. 作为消费者，我想要看到商品的详细描述（产地、规格、卖点标签），以便确认商品是否符合我的需求。
9. 作为消费者，我想要通过数量选择器调整购买数量，以便按需下单。
10. 作为消费者，我想要看到"加入购物车"和"立即购买"两个购买入口，以便选择我偏好的购买方式。
11. 作为消费者，我想要看到其他用户的评价和晒单图片，以便参考真实购买反馈。
12. 作为消费者，我想要看到相关推荐商品，以便发现更多感兴趣的商品。
13. 作为消费者，我想要通过面包屑导航了解当前页面位置，以便快速返回上级分类。
14. 作为消费者，我想要在页脚找到配送说明、售后服务和联系方式，以便在购买前确认物流和售后保障。
15. 作为品牌方，我想要页面的视觉风格统一且具有精品感，以便建立品牌识别度。

## Implementation Decisions

### 技术架构

- 纯静态 HTML/CSS/JS 项目，无框架依赖，无构建步骤
- CSS 使用 CSS Custom Properties（CSS 变量）管理设计系统的颜色、字体、间距令牌
- JS 使用原生 ES6+，不引入第三方库
- 所有图片素材使用外部 URL 引用（Midjourney 生成后托管），不在仓库中存储二进制文件
- 目标分辨率：1440px 桌面端，暂不做响应式适配

### 页面与模块

**页面：**
- `index.html` — 首页
- `product-detail.html` — 阳光草莓礼盒商品详情页

**共享基础组件（CSS class-based，无 JS 框架）：**
- `button` — 三种变体：primary（主绿色实心）、outline（绿色描边白底）、ghost（纯文字）
- `badge` — 商品标签（新鲜标签、促销标签、卖点标签）
- `price` — 价格展示（当前价格 + 可选的划线原价）
- `rating` — 星级评分（纯 CSS 实现，支持半星）
- `quantity-stepper` — 数量选择器（减号/数字/加号，最小 1）
- `search-input` — 搜索输入框

**首页模块：**
- `header` — 顶部固定导航，含 Logo、导航菜单、搜索框、购物车图标、登录按钮
- `hero` — 全宽首屏主视觉，标题/副文案/CTA 按钮叠在背景图上
- `category-grid` — 6 列分类卡片网格（图标 + 标签文字）
- `product-card` — 商品卡片（图片 + 名称 + 卖点 + 规格 + 价格 + 新鲜标签 + 加购按钮）
- `promo-banner` — 限时优惠横幅（浅绿背景 + 倒计时 + 促销商品 + 折扣价）
- `trust-badges` — 4 列品质保障（图标 + 标题 + 简短说明）
- `footer` — 多列页脚（品牌简介 + 导航链接 + 联系方式）

**商品详情页模块：**
- `breadcrumb` — 面包屑导航（首页 > 水果鲜选 > 阳光草莓礼盒）
- `image-gallery` — 左侧主图 + 下方 4 张缩略图，点击缩略图切换主图
- `product-info` — 商品名称、评分、价格、规格、卖点标签、配送信息
- `purchase-panel` — 数量选择器 + 加入购物车 + 立即购买 + 收藏按钮
- `tab-panel` — 三个标签页切换：商品详情 / 产地信息 / 用户评价
- `review-card` — 用户头像 + 星级 + 评价文字 + 晒单缩略图
- `related-products` — 相关推荐商品网格（复用 product-card）

### 设计系统

**色彩令牌（CSS Custom Properties）：**
```
--color-primary: #3C8C5A
--color-primary-light: #EAF6EF
--color-accent-yellow: #F7D96B
--color-accent-red: #E95B4A
--color-text-primary: #1F2A24
--color-text-secondary: #6B756F
--color-bg-page: #FAFCF9
--color-bg-card: #FFFFFF
--color-border: #E3EAE5
```

**字体：**
- 中文：Noto Sans SC（思源黑体）
- 英文/数字：Inter
- 标题：Semibold(600) / Bold(700)
- 正文：Regular(400)
- 价格/促销：Bold(700)

**间距系统：** 基于 4px 的递增间距（4, 8, 12, 16, 20, 24, 32, 40, 48, 56, 64, 72, 80）

**圆角：** 统一 8px（卡片、按钮、输入框）

**图片占位：** 开发阶段使用占位图服务或本地纯色占位块，素材就绪后替换为真实 Midjourney 图片 URL

### 交互行为

- 分类卡片 hover：轻微阴影加深 + 边框颜色变化
- 商品卡片 hover：阴影加深 + 图片微缩放（transform: scale(1.03)）
- 缩略图点击：切换主图显示，当前缩略图有边框高亮
- Tab 切换：点击标签切换对应内容面板，当前标签底部有绿色下划线
- 数量选择器：最小值 1，最大值 99，减号在数量为 1 时置灰不可点击
- 加入购物车：点击后按钮短暂显示"已加入"反馈（文字切换 + 1.5s 恢复）
- 搜索框：focus 时边框变为 primary 绿色

### 数据结构

商品卡片数据以静态 HTML 硬编码，不使用 JS 动态渲染。每个商品卡片包含：图片 src、商品名、卖点文字、规格、价格、新鲜标签类型。

### 图片素材

所有商品图和图标由 Midjourney 生成，外部托管。前端通过 `<img src="...">` 引用。素材清单：Hero 背景图 (16:7)、草莓礼盒主图 (4:3)、草莓缩略图 ×4、商品卡片图 ×6 (1:1)、分类图标 ×6 (1:1)、品质保障图标 ×4、评价晒单图 ×3。

## Testing Decisions

### 测试策略

纯 HTML 项目以手动视觉验证为主，辅以交互行为的功能性检查：

**什么构成好的测试：** 验证页面在目标分辨率 1440px 下的视觉还原度、交互元素的响应行为、以及所有模块的存在性和正确排列。测试用户可见的行为，不测试 CSS 实现细节。

**测试范围：**
- 所有共享基础组件的交互行为（按钮 hover/active、数量选择器边界值、搜索框 focus）
- 首页 7 个模块的完整性验证（header、hero、category-grid、product-card 列表、promo-banner、trust-badges、footer）
- 商品详情页交互流程（缩略图切换、Tab 切换、数量选择、加购反馈）
- 跨浏览器验证（Chrome、Edge、Firefox 最新版）
- 视觉设计令牌一致性（颜色、字体、间距是否与设计规范匹配）

**测试形式：** 手工测试清单（checklist），在浏览器中逐项验证。不引入自动化测试框架，因为本项目核心交付物是视觉界面而非业务逻辑。

### 测试清单示例

1. 页面在 1440px 宽度下无水平滚动条、无元素重叠
2. 所有图片正确加载，无裂图
3. 所有 hover 状态正常触发
4. 数量选择器边界值正确（最小值 1，不可减至 0）
5. 缩略图点击正确切换主图
6. Tab 切换正确显示对应内容

## Out of Scope

- 用户登录/注册完整流程
- 购物车完整结算流程（购物车页面、订单确认、支付）
- 移动端响应式适配
- 小程序版本
- 后台商品管理系统
- 真实 API 对接（商品数据、库存、订单均为静态模拟）
- SEO 优化（meta 标签基础填写即可，不做深度 SEO）
- 无障碍访问（ARIA 标签、键盘导航）
- 浏览器兼容 IE 或旧版 Edge
- 性能优化（Lazy loading、CDN、Brotli 压缩等）
- 用户行为埋点与数据分析
